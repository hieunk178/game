# 3D Models Directory

Place `.glb` model files here. The game will automatically load them.

## Required Model Files

| File Name | Object | Suggested Search (poly.pizza) |
|-----------|--------|-------------------------------|
| `desk.glb` | Bàn làm việc | "desk" or "office desk" |
| `chair.glb` | Ghế xoay | "office chair" |
| `laptop.glb` | Laptop | "laptop" |
| `lamp.glb` | Đèn bàn | "desk lamp" |
| `coffee.glb` | Tách cà phê | "coffee cup" or "mug" |
| `clock.glb` | Đồng hồ treo tường | "wall clock" |
| `bookshelf.glb` | Kệ sách | "bookshelf" |
| `plant.glb` | Chậu cây cảnh | "potted plant" |
| `bed.glb` | Giường ngủ | "bed" |
| `guitar.glb` | Guitar | "guitar" |
| `backpack.glb` | Balo | "backpack" |

## Where to Download

1. **Poly Pizza** (Recommended): https://poly.pizza
2. **Kenney Furniture Kit**: https://kenney.nl/assets/furniture-kit 

3. **Quaternius**: https://quaternius.com

All models should be CC0 (Public Domain) licensed.
Low-poly (< 5000 tri each) recommended for best web performance.
If a model file is missing, the game falls back to the built-in procedural mesh.
